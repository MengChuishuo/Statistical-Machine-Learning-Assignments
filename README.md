# Statistical Machine Learning Projects

This repository contains a series of assignments completed for my Statistical Machine Learning course. These cover a wide range of core machine learning concepts, from fundamental linear models to advanced techniques like ensemble methods and Support Vector Machines. Demonstrate proficiency in data analysis, model building, and performance evaluation through practical applications on real-world datasets.

---

### Key Concepts & Methods

-   **Regression Models**: Multiple Linear Regression, K-Nearest Neighbors (KNN), Polynomial Regression, Regression Splines, Smoothing Splines, Generalized Additive Models (GAMs).
-   **Classification Models**: Logistic Regression, Linear & Quadratic Discriminant Analysis (LDA/QDA), Decision Trees, Random Forest, Gradient Boosting, Support Vector Machines (SVM).
-   **Model Evaluation & Selection**: Cross-Validation (CV), Bootstrapping, Adjusted R-squared, Akaike Information Criterion (AIC), ROC/AUC Analysis, Confusion Matrices.
-   **Implementation from Scratch**: K-Nearest Neighbors (KNN) Regression, Regression Tree with a custom absolute error loss function.

---

### Assignment 1: Regression Fundamentals & KNN Implementation

-   Analyzed the relationship between predictors and life expectancy using Multiple Linear Regression, performing coefficient interpretation, confidence interval analysis, and model selection with AIC.
-   Implemented the K-Nearest Neighbors regression algorithm from scratch to predict Boston housing prices, evaluating the impact of data standardization and the choice of `K` on model performance and computational time.

### Assignment 2: Classification Methods & Model Validation

-   Built and compared multiple classifiers (Logistic Regression, LDA, QDA) on a breast cancer dataset, evaluating performance using ROC curves and AUC.
-   Applied K-Fold and Leave-One-Out Cross-Validation to select optimal model complexity for polynomial regression and kernel smoothing.
-   Utilized Bootstrapping to construct confidence and prediction intervals for models on the Titanic survival dataset, demonstrating a powerful technique for statistical inference.

### Assignment 3: Tree-Based & Non-Linear Models

-   Implemented a complete Regression Tree algorithm from scratch, featuring a custom absolute error loss function and user-defined stopping criteria.
-   Applied a suite of non-linear models—including Polynomial Regression, Regression Splines, Smoothing Splines, and Generalized Additive Models to predict the volume of Black Cherry trees.
-   Developed Classification Trees and Random Forests to predict fraudulent firms from an audit risk dataset, including hyperparameter tuning for the number of variables considered at each split (`m`).

### Assignment 4: Support Vector Machines (SVM) & Advanced Ensemble Methods

-   Built and tuned Support Vector Machine classifiers with both linear and radial kernels for the MNIST handwritten digit recognition task, performing both binary and multi-class classification.
-   Deployed Random Forest and Gradient Boosting models for a multi-class text classification problem on the 20 Newsgroups dataset, identifying the most important keywords for classification.
-   Conducted a comprehensive performance comparison of various classifiers (Random Forest, Boosting, LDA, QDA, SVM) on high-dimensional datasets, providing in-depth analysis and insights.
